# Miniguia de Estudos: ABAP Cloud & RESTful ABAP Programming Model (RAP)

Este repositório serve como um **caderno temático e centralizador de estudos** focado na evolução do ecossistema SAP moderno. O foco principal é o domínio do **ABAP Cloud** e, especificamente, do **RESTful ABAP Programming Model (RAP)**, que representam o padrão ouro atual para o desenvolvimento de extensões e aplicações robustas, escaláveis e otimizadas na SAP Business Technology Platform (BTP) e no SAP S/4HANA.

---

## 🎯 Assunto de Interesse

O ecossistema SAP passou por uma transformação profunda com o advento do desenvolvimento "Clean Core" e a transição para a nuvem. Este caderno aborda a transição do ABAP tradicional para o **ABAP Cloud**, com foco total em:
* **RESTful ABAP Programming Model (RAP):** Arquitetura e implementação de serviços de ponta a ponta (OData V2/V4).
* **Core Data Services (CDS Views):** Modelagem de dados avançada, projeções e otimização de performance.
* **Business Object (BO) Behavior:** Implementação de lógicas de negócio estruturadas através de *determinations*, *validations* e *actions*.
* **Modernização de Competências:** Substituição de práticas legadas por metodologias modernas alinhadas às melhores práticas globais da SAP.

---

## 🚀 Objetivos de Estudo

Este material foi estruturado para alcançar os seguintes objetivos claros e mensuráveis:

1. **Domínio Teórico e Prático do RAP:** Compreender os cenários *managed* e *unmanaged* do framework, sabendo quando e como aplicar cada abordagem em projetos reais.
2. **Construção de Extensões Clean Core:** Aprender a criar aplicações desacopladas do núcleo standard, garantindo atualizações de sistema (*upgrades*) sem fricção.
3. **Otimização de Performance:** Aplicar conceitos avançados de modelagem em CDS Views e análise de planos de execução para garantir máxima eficiência na camada de base de dados (SAP HANA).
4. **Repositório de Consulta Rápida:** Consolidar códigos de exemplo, *cheat sheets* e anotações arquiteturais estruturadas para acelerar o desenvolvimento no dia a dia profissional.
